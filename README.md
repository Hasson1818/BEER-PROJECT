# BEER PROJECT

משחק תלת־ממדי בגוף ראשון שרץ בדפדפן, ומלווה את השלבים בדרך לצבא. מתחילים בצו הראשון.

**לשחק עכשיו (גם בטלפון):** https://hasson1818.github.io/BEER-PROJECT/

האתר מתעדכן לבד: בכל העלאה ל־`main`, GitHub Actions בונה את המשחק ומפרסם אותו (`.github/workflows/deploy.yml`). זה לוקח כדקה.

## הרצה

צריך [Node.js](https://nodejs.org/). מתוך התיקייה הראשית של הריפו, בפעם הראשונה:

```bash
npm install
```

ואז:

```bash
npm run dev
```

ופותחים את http://localhost:5173. העמוד הראשי מעביר אוטומטית למסך הפתיחה.

### לשחק מהטלפון

1. הטלפון צריך להיות מחובר לאותה רשת (Wi‑Fi) כמו המחשב.
2. אחרי `npm run dev` מופיעה במחשב שורה כמו `Network: http://10.100.102.17:5173/`.
3. פותחים את הכתובת הזאת בדפדפן של הטלפון.

בטלפון יש ג׳ויסטיק לתנועה, גרירה על המסך כדי להסתכל, וכפתור "פעולה". הכי נוח לשחק כשהטלפון לרוחב, ובאנדרואיד יש גם כפתור למסך מלא.

אם הטלפון לא מצליח להתחבר, צריך לאשר ל-Node.js גישה ב"רשתות פרטיות" בחומת האש של Windows.

## שמירה

המשחק נשמר בדפדפן (`localStorage`, מפתח `beer-project-save`) אחרי כל תחנה. "המשך מאיפה שעצרת" במסך הראשי ממשיך מהתחנה האחרונה שהושלמה.

## דמויות מקרוב

הדמויות מצוירות מצורות פשוטות כדי שהמשחק יישאר קל בטלפון. את הדמויות הכי קרובות למצלמה (עד 12 במחשב, 8 בטלפון) מחליף מודל מפורט עם שלד, שנעשה בבלנדר: גוף מעוצב, פנים, ידיים, מגפיים, חגורה, כיסים וצווארון. הוא מונע מאותם מפרקים כמו הדמות הפשוטה, אז כל התנוחות והאנימציות עובדות בשניהם.

- הקוד: [`shared/engine/detail.js`](shared/engine/detail.js)
- קובץ הבלנדר לעריכה: [`shared/engine/assets/character.blend`](shared/engine/assets/character.blend)
- הסקריפט שבונה אותו ומייצא את `character.json`: [`tools/blender/build_character.py`](tools/blender/build_character.py)

## התקדמות והישגים

במסך הראשי יש "הדרך שלי לצבא": פס התקדמות באחוזים עם דרגה, חייל קטן שרץ בקצה הפס, ורשימה של מה שנשאר. לכל הישג יש ערך באחוזים, וכל ההישגים יחד שווים 100%. ההישגים נשמרים בדפדפן (`beer-project-achievements`) והם מקבלים הודעה קופצת באמצע המשחק כשמקבלים אותם.

הרשימה והערכים נמצאים ב־[`shared/achievements.js`](shared/achievements.js). כדי להוסיף הישג: מוסיפים אותו לרשימה שם, וקוראים ל־`unlock('המזהה')` בנקודה המתאימה בשלב. מי שסיים שלב לפני שההישגים נוספו מקבל את הישגי הסיום שלו אוטומטית, בלי הודעה.

## סאונד

למשחק יש אווירה (רוח, צרצרים, המולת אולם, רעש חדר), צעדים וזחילה בחול, חפירה, שריקת עצירה, נשימה כבדה כשנגמר הכוח, מטוסים מעל גבעת הגיבוש, הודעות SMS והודעת הישג. כפתור 🔊 בפינה (או המקש `M`) משתיק הכול, וההעדפה נשמרת.

הצלילים הם חינמיים מ־Pixabay, ורשימה מלאה עם שמות היוצרים נמצאת ב־[`CREDITS.md`](shared/engine/assets/sounds/CREDITS.md). הקבצים המקוריים נחתכים ומקבלים לולאה חלקה ועוצמה אחידה בעזרת [`tools/sounds/process-sounds.mjs`](tools/sounds/process-sounds.mjs). הקוד שמנגן אותם נמצא ב־[`shared/engine/sound.js`](shared/engine/sound.js).
