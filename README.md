# BEER PROJECT

משחק תלת־ממדי בגוף ראשון שרץ בדפדפן, ומלווה את השלבים בדרך לצבא. מתחילים בצו הראשון.

## הרצה

צריך [Node.js](https://nodejs.org/). מתוך התיקייה הראשית של הריפו, בפעם הראשונה:

```bash
npm install
```

ואז:

```bash
npm run dev
```

ופותחים את http://localhost:5173. העמוד הראשי מעביר אוטומטית למסך הפתיחה.

## פרויקטים בריפו

| תיקייה | מה זה |
| --- | --- |
| [`main-screen`](main-screen/) | מסך הפתיחה: התחלת משחק חדש או המשך מהשמירה |
| [`tzav-rishon`](tzav-rishon/) | השלב הראשון, יום הצו הראשון בלשכת הגיוס |
| `shared` | קוד משותף: שמירת משחק, ציור הדגל |

## שמירה

המשחק נשמר בדפדפן (`localStorage`, מפתח `beer-project-save`) אחרי כל תחנה. "המשך מאיפה שעצרת" במסך הראשי ממשיך מהתחנה האחרונה שהושלמה.
