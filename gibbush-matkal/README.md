# גיבוש מטכ״ל / שלדג

"גיבוש היחידה": הגיבוש המאוחד לסיירת מטכ״ל, שלדג, 669 וחטיבת הקומנדו. מגיעים אליו בזימון מיום הסיירות (במשחק אפשר גם בלי). השלב משתמש בעולם הדיונה ובתרגילים של [`yom-sayarot`](../yom-sayarot/).

## מה אמיתי ומה של המשחק

- **רשמי:** הגעה דרך יום הסיירות, מיון משותף לארבע היחידות, "יעד קביעה" שנשמר עד הסוף, ודראפט 669/קומנדו ושבוע ראיונות (נוסח 2021).
- **לפי דיווחים בתקשורת:** חמישה ימים, ונתוני הלוחמות (מרץ 2024: 11 הגיעו, 7 סיימו, 0 התקבלו; נובמבר 2024 הראשונה התקבלה).
- **לפי עדויות** (כ־15 תחקירים בגוף ראשון מ־2020 עד 2026, רובם באתר הכנה אחד): המיקום, השעות, האקטים והמספרים שלהם (שק 20 ק״ג, "הראשון ל־10/15 עוצר"), הניפוי ביום ג׳, הסוציומטרי, הראיון ואופן מסירת התוצאות.
- **בדיוני:** נוהל הוויתור ואיך מסדר הניפויים נראה מבפנים. לא נמצאה עליהם אף עדות.
- **של המשחק:** מספר הסבבים (מקוצר: 3–4 במקום 10–15), משקלות הציון (פיזי 30%, אמינות 20%, ראש 20%, חוליה 20%, ראיון 10%) והקווים לניפוי ולכל תוצאה. הם כתובים במסך התוצאה כהחלטה של המשחק.
