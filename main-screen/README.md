# מסך ראשי (main-screen)

מסך הפתיחה של המשחק: רקע תלת־ממדי של שער בסיס קליטה ומיון בשקיעה, ותפריט עם הכפתורים "התחל משחק" ו"המשך מאיפה שעצרת".

נבנה עם [Three.js](https://threejs.org/) (גרפיקה תלת־ממדית) ו-[Vite](https://vite.dev/) (שרת פיתוח ובנייה).

## הרצה

צריך [Node.js](https://nodejs.org/) מותקן. מתוך התיקייה `main-screen`:

```bash
npm install
npm run dev
```

ואז לפתוח בדפדפן את הכתובת שמופיעה (בדרך כלל http://localhost:5173).

## קבצים

| קובץ | מה יש בו |
| --- | --- |
| `index.html` | מבנה המסך: התיקייה, הכותרת והכפתורים |
| `src/style.css` | העיצוב של התפריט |
| `src/scene.js` | הסצנה התלת־ממדית ברקע |
| `src/main.js` | מחבר הכול, ומה קורה כשלוחצים על הכפתורים |

## מצב נוכחי

- הכפתורים קיימים, אבל עוד לא מובילים לשלב. לחיצה מציגה הודעה קצרה.
- "המשך" בודק אם יש שמירה בדפדפן (`localStorage`, מפתח `beer-project-save`). עדיין אין מערכת שמירה, ולכן תמיד כתוב "אין שמירה עדיין".
