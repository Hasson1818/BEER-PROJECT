# מסך ראשי (main-screen)

מסך הפתיחה של המשחק: רקע תלת־ממדי של שער בסיס קליטה ומיון בשקיעה, ותפריט עם שני כפתורים:

- **התחל משחק**: מתחיל את שלב [צו ראשון](../tzav-rishon/) מההתחלה.
- **המשך מאיפה שעצרת**: ממשיך מהשמירה. אם אין שמירה, מוצגת הודעה.

להרצה, ראו את ה־[README הראשי](../README.md).

## קבצים

| קובץ | מה יש בו |
| --- | --- |
| `index.html` | מבנה המסך: התיקייה, הכותרת והכפתורים |
| `src/style.css` | העיצוב של התפריט |
| `src/scene.js` | הסצנה התלת־ממדית ברקע |
| `src/main.js` | מחבר הכול, ומה קורה כשלוחצים על הכפתורים |
