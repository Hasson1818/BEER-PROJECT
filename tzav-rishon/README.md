# שלב 1: צו ראשון (tzav-rishon)

יום הצו הראשון בלשכת הגיוס, בגוף ראשון. עוברים את כל התחנות לפי הסדר שבו קוראים למספר שלכם על המסך.

## מהלך השלב

1. **בבית**: אורזים את התיק (תעודת זהות, הצו, שאלון רפואי חתום, בדיקת שתן, משקפיים, אוכל). מחשבון לא לוקחים.
2. **בידוק ביטחוני**: המאבטח בודק את התיק, ואז עוברים בשער.
3. **ניתוב**: עומדים בתור (אם יוצאים מהתור, מאבדים את המקום), מציגים תעודה ומקבלים מדבקת ברקוד עם מספר.
4. **אולם ההמתנה**: יושבים ומחכים שהמספר יופיע במסכים. כשיושבים על כיסא, הזמן עובר מהר יותר.
5. **אימות נתונים**: כתובת, משפחה, לימודים ועברית.
6. **מבחן ממוחשב (דפ״ר)**: ארבעה פרקים עם זמן מוגבל (אנלוגיות מילוליות, חשיבה כמותית, הבנת הוראות, חשיבה צורנית) ומבחן קשב.
7. **בדיקות רפואיות**: מדידות (גובה, משקל, לחץ דם, דופק), בדיקת ראייה (לוח E ולוחות עיוורון צבעים), ורופא שקובע פרופיל.
8. **ראיון אישי**: שבע שאלות עם מאבחנת. הציון לא נאמר.
9. **סיום**: חוזרים לניתוב, יוצאים מהלשכה, ו"שבועיים אחר כך" מקבלים את התוצאות בטלפון.

אחרי כל תחנה מופיע כרטיס "ידעת?" עם מידע אמיתי על התחנה.

## שליטה

| מחשב | טלפון |
| --- | --- |
| `W` `A` `S` `D` או חיצים: הליכה | ג׳ויסטיק משמאל |
| עכבר: הסתכלות (לוחצים על המסך כדי לנעול את העכבר) | גרירה על המסך |
| `E` או לחיצה: פעולה / דיבור | כפתור "פעולה" |
| `1`–`4`: בחירת תשובה | לחיצה על התשובה |
| `Shift`: הליכה מהירה, `Esc`: עצירה | |

## מה פשוט יותר מבמציאות

- **סדר התחנות**: במציאות הוא משתנה לפי העומס. במשחק הוא קבוע.
- **משך היום**: אמיתי. כל תחנה מקדמת את השעון.
- **שאלות המבחן**: מקוריות ומעטות. המבחן האמיתי אדפטיבי וארוך יותר.
- **הפרופיל**: נקבע לפי סעיפי ליקוי רפואיים. במשחק יש רק כמה מקרים לדוגמה.
- **הקב״א**: לפי מדריכי הכנה הוא מורכב מהדפ״ר, ההשכלה והראיון (בערך 50% / 17% / 33%). במשחק החישוב פשוט.

למידע רשמי ועדכני: אתר [מתגייסים](https://www.mitgaisim.idf.il/).
